# Pumpkin Teleport Script

This project contains a Roblox script that teleports the player to random pumpkins in the workspace. It is designed to work with Delta Executor and provides a user-friendly GUI for easy execution.

## Install

1. Download the script from the GitHub repository.
2. Open your Roblox game in Roblox Studio.
3. Place the script in the `ServerScriptService` in Roblox Studio.

## Use

1. Ensure you have Delta Executor installed and running.
2. Start your Roblox game.
3. A GUI button labeled 'RUN PUMPKINS' will appear on the screen.
4. Click the button to start teleporting to random pumpkins in the workspace.
